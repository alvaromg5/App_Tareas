# App_Tareas

Aplicación multiplataforma de gestión de tareas desarrollada con Python y Flet como proyecto académico de 2º ASIR.

## Funcionalidades

- Añadir, editar y eliminar tareas.

- Marcar tareas como completadas.

- Evitar tareas duplicadas.

- Contador dinámico de tareas pendientes.

- Eliminar todas las tareas completadas.

## Tecnologías utilizadas

- Python

- Flet

## Descargas

Disponible para Android (.apk) y Windows (.exe) en el apartado Releases.
